Date recorded: 2026-09-25

The user confirmed that the teammate firmware/protocol and electrical proof of
concept passed on the tested hardware configuration. The accompanying photos
are preserved here as supporting setup evidence:

- `poc-node32lite-wiring.png` — Node32 Lite development board with the bench
  wiring attached and USB power/programming connection present.
- `poc-esp32-powered.png` — ESP32 development board powered over USB with its
  indicator illuminated.

These still photographs document the physical powered setup. They do not, by
themselves, display protocol traces, measured voltage levels, console screen
output, or game-image contents. Functional operation is therefore recorded as
a user/team-reported bench result. Acceptance is limited to the tested console,
donor harness, firmware and protocol configuration; it is not a claim of full
PS1 serial handshaking or untested-console compatibility.
