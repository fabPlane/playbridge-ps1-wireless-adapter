# PlayBridge V3.0 J2 serial fast-pass

Date: 2026-09-25  
Status: **layout complete; DO NOT ORDER pending PS1 electrical validation**

## Result

J2 now uses a dedicated ESP32 UART and does not reuse the controller/SNAC GPIOs or the USB programming/debug UART.

| Function | ESP32 signal | Module pad | Board path | J2 contact |
| --- | --- | ---: | --- | ---: |
| PS1 serial transmit | GPIO17 / UART2 TX | U1.28 | `U2_TX_RAW` -> R30 1 kOhm -> `PS1_RXD` | J2.1 |
| PS1 serial receive | GPIO16 / UART2 RX | U1.27 | `PS1_TXD` -> R31 1 kOhm -> `U2_RX_RAW` | J2.4 |
| Signal reference | GND | ground plane | GND | J2.7 |

J2 contacts 2, 3, 5, 6, 8 and 9 remain NC. J2 is a keyed physical harness connector and is explicitly **NOT USB**.

The existing interfaces remain separate:

- J1 controller/SNAC GPIOs remain GPIO19, GPIO21, GPIO32, GPIO33 and GPIO34.
- USB-C programming/debug remains UART0 on GPIO1 TX and GPIO3 RX through the CH340C path.
- J2 serial uses UART2 on GPIO17 TX and GPIO16 RX.

## Release hold

R30 and R31 are provisional 1 kOhm series resistors for bench configuration. They provide current limiting but do not prove voltage compatibility or implement level shifting. Keep `ordering/DO-NOT-ORDER.md` active until the PS1 serial logic levels, direction, idle/startup behavior, baud rate, supported console revisions, and donor-harness pinout are verified on hardware.
