# V3.0 combined firmware verification

Date: 2026-09-25

## Implemented

- Existing controller sketch retained unchanged.
- Combined experimental sketch added under
  `firmware/playbridge_combined_bridge/`.
- One AP/STA Wi-Fi manager with Wi-Fi sleep disabled for throughput trials.
- Existing HTTP controller routes retained on port 80; bridge diagnostics added
  at `/bridge/status`.
- UART2 GPIO16 RX/GPIO17 TX raw bridge on TCP 3333.
- PSB1 baud/abort control on UDP 3334 with exact success echo.
- Dedicated core-0 owner task for UART2 and both bridge sockets.
- Partial-write retention, nonblocking TCP sends, one data client, queue cleanup,
  backpressure timeout and UART-error abort.
- Bounded UART drain before baud changes.
- Duplicate PSB1 requests are re-acknowledged without repeating an abort.
- Controller input is latched once per PS1 poll and returns to neutral after a
  lost browser heartbeat while allowing legitimate long holds.
- Wi-Fi configuration is nonblocking and rejected during transfers.

## Verification performed

- Target: `esp32:esp32:node32s`

The compile and host tests do not prove PS1 voltage compatibility, UART signal
integrity, controller latency under load, or game compatibility. Follow the
acceptance sequence in the combined firmware README before calling it stable.
